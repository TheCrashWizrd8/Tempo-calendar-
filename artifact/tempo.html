Setup guide

Your phone writes tiny events into a hidden Google calendar. Tempo reads them when you open it. Nothing else can see them.

  1. Make the hidden calendar. On a computer, open Google Calendar → Create new calendar and name it exactly Tempo location. Then untick it in the calendar list so it stays hidden.
  1. Sync it to your iPhone. Settings → Calendar → Accounts → your Google account → make sure Calendars is on. You may need to wait a minute for the new calendar to appear.
  2. Create the shortcut. Shortcuts app → + → name it Tempo ping. Add these two actions:
    • Get Current Location
    • Add New Event. Calendar: Tempo location. Title: type Tempo , then tap Select Variable → Current Location, tap that bubble and choose Latitude. Type a comma, then add the same variable again with Longitude. Start and End: Current Date.
    The title should look like Tempo [Latitude],[Longitude].
  3. Test it. Tap ▶ in the shortcut, wait about a minute for it to sync, then tap Check now above.
  4. Make it run by itself. Shortcuts → Automation → +. For each trigger choose Run Immediately and the action Run Shortcut → Tempo ping:
    • App → Is Opened: choose 3 to 5 apps you use every day. This gives the most samples, spread across your day.
    • Time of Day (optional): e.g. 8 AM, 1 PM, 6 PM, 10 PM.
  1. Make an applet per place at ifttt.com/create.
    • If This: Location → You enter or exit an area. Pick the area, e.g. your library.
    • Then That: Google Calendar → Quick add event. Calendar: Tempo location. Text: Tempo {{EnteredOrExited}} Library, with the place name at the end.
  2. Allow location for the IFTTT app on your phone (Always).
  3. Test it by walking in or out of the area, then tap Check now above.

IFTTT only knows places you draw yourself, and its free plan limits how many applets you can have. Shortcuts finds new places on its own. You can use both.
