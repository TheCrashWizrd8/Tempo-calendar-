Setup guide

Your phone writes tiny events into a hidden Google calendar. Tempo reads them when you open it. Nothing else can see them.

  1. Make the hidden calendar. On a computer, open Google Calendar → Create new calendar and name it exactly Tempo location. Then untick it in the calendar list so it stays hidden.
  1. Put it on your iPhone. Shortcuts can only use calendars your iPhone's Calendar app can see.
    • Add your Google account: Settings → Apps → Calendar → Calendar Accounts → Add Account → Google (on older iOS: Settings → Calendar → Accounts). Make sure Calendars is on.
    • Google doesn't send new calendars to iPhones by itself. Open calendar.google.com/calendar/syncselect, tick Tempo location and tap Save.
    • In the Calendar app, tap Calendars at the bottom and check that “Tempo location” is listed. It can take a minute.
  2. Create the shortcut. Shortcuts app → + → name it Tempo ping. Add these two actions:
    • Get Current Location
    • Add New Event (tap Add Action and search “event”; it's under Calendar). Calendar: Tempo location. Title: type Tempo , then tap Select Variable → Current Location, tap that bubble and choose Latitude. Type a comma, then add the same variable again with Longitude. Start and End: Current Date.
    The title should look like Tempo [Latitude],[Longitude].
  3. Test it. Tap ▶ in the shortcut, wait about a minute for it to sync, then tap Check now above.
  4. Make it run by itself. Shortcuts → Automation → +. For each trigger choose Run Immediately and the action Run Shortcut → Tempo ping:
    • Exactly 10 minutes after each event starts (recommended). iPhones can't run a shortcut when an event begins, but they can when an email arrives. Tempo adds a tiny “Tempo check-in” to your hidden calendar 10 minutes into each event, Google emails you at that minute, and the email runs your shortcut.
      2. Make sure your Gmail account is in the iPhone Mail app (Settings → Apps → Mail → Mail Accounts).
      3. Shortcuts → Automation → + → Email. Sender: calendar-notification@google.com. Subject contains: Tempo check-in. Choose Run Immediately, then the action Run Shortcut → Tempo ping.
      4. Optional: in Gmail, filter those emails to mark them as read so they don't pile up.
      Prefer fixed weekly times instead?

      Make one Time of Day automation per line: choose the time, Weekly, and tick the days shown.

    • App → Is Opened (optional, extra samples): choose a few apps you use every day.
  1. Make an applet per place at ifttt.com/create.
    • If This: Location → You enter or exit an area. Pick the area, e.g. your library.
    • Then That: Google Calendar → Quick add event. Calendar: Tempo location. Text: Tempo {{EnteredOrExited}} Library, with the place name at the end.
  2. Allow location for the IFTTT app on your phone (Always).
  3. Test it by walking in or out of the area, then tap Check now above.

IFTTT only knows places you draw yourself, and its free plan limits how many applets you can have. Shortcuts finds new places on its own. You can use both.

One calendar

New events always go to your main calendar. You can also move what's already in your other calendars into it.

Move events from

Tempo copies each event into your main calendar, then removes the original. Repeating events move as a whole series, so a one-off change to a single lesson goes back to the usual pattern. Events other people invited you to stay where they are. Anyone you share these calendars with will stop seeing the moved events. You can undo the move.
