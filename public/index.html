Background learning

      
    

    
Your phone sends its location to Tempo a few times a day, even when Tempo is closed. This takes about 3 minutes, once.


    

      
    
        
  1. 
          Create the shortcut. Open the Shortcuts app → Shortcuts tab → +. Name it Tempo ping.
        
    2. 
        
  2. 
          Add “Get Current Location”. Search for it in the action list and tap it.
        
    3. 
        
  3. 
          Add “Get Contents of URL”. Tap the blue URL placeholder and paste your link:
          
    
          Tap the › arrow to show more options, then set:
          
      
            
    • Method: POST
      • 
            
    • Request Body: JSON
      • 
            
    • Tap Add new field → Number. Key lat . For the value, tap Select Variable → Current Location, then tap that bubble again and choose Latitude.
      • 
            
    • Same again for key lng  → Longitude.
      • 
          
    
        
    4. 
        
  4. 
          Test it: tap ▶ in the shortcut. If asked, allow location access.
          
    Waiting for your first location…
    
        
    5. 
        
  5. 
          Make it run on its own. Go to the Automation tab → +, and create one or more of these. For each one, choose Run Immediately, then add the action Run Shortcut → Tempo ping.
          
      
            
    • App → “Is Opened” → pick 3–5 apps you use every day (Messages, Instagram…). This gives the most samples, spread naturally through your day.
      • 
            
    • Time of Day → e.g. 9 AM, 1 PM, 6 PM, 10 PM (one automation each).
      • 
            
    • Wi-Fi → when joining your home or campus network.
      •
