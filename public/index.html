Location learning

        

          
          
For learning in the background, add a phone automation that sends your location to your private link:

          

          

            How to set it up
            
iPhone (Shortcuts): Automation → “Time of Day” (e.g. every hour, or several times a day) and/or “Arrive/Leave” for places → Run Immediately. Actions: Get Current Location → Get Contents of URL with your link above, Method POST, Request Body JSON with lat = Latitude and lng = Longitude.

            
Android (Tasker / Automate): a time or location-change trigger that sends an HTTP POST with JSON {"lat": %LOCN_LAT, "lng": %LOCN_LON} — or {"location": "%LOC"} — to the link.

            
Anyone with this link can add location points to your account, so keep it private.
